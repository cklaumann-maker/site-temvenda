## Próximos Passos

Agora você pode:

### 1. Iniciar o aplicativo

```bash
cd rotina-app
pnpm dev
```

### 2. Configurar URLs no Supabase Auth (OBRIGATÓRIO)

1. Acesse: https://supabase.com/dashboard/project/mgcoyeohqelystqmytah
2. **Settings** → **Authentication** → **URL Configuration**
3. Adicione `http://localhost:3001` em **Site URL**
4. Adicione `http://localhost:3001/**` em **Redirect URLs**
5. **Save**

### 3. Testar

1. Acesse: http://localhost:3001/login
2. Digite um email
3. Clique em "Enviar Magic Link"
4. Verifique seu email
5. Clique no link
