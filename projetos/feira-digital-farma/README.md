# Feira Digital Farma

Site de divulgação do evento Feira Digital Farma - Onde inovação, mídia digital e negócios se encontram na farmácia real.

## 📁 Estrutura do Projeto

```
feira-digital-farma/
├── index.html                      # Home - O Evento
├── distribuidoras.html             # Para Distribuidoras Parceiras
├── industrias.html                 # Para Indústrias Parceiras
├── parceiros-corporativos.html     # Para Parceiros Corporativos
├── contato.html                    # Contato/Inscrição
├── assets/
│   ├── css/
│   │   └── style.css               # Estilos compartilhados
│   ├── js/
│   │   └── main.js                 # JavaScript compartilhado
│   └── images/                     # Imagens do projeto
└── README.md
```

## 🎨 Páginas

### 1. Home (index.html)
Página principal do evento com todas as seções:
- Hero Section
- O Contexto do Mercado
- O Que É a Feira Digital Farma
- Para Quem É o Evento
- Inovação na Prática
- Negócios Acontecem Aqui
- **Programação (em desenvolvimento)**
- Parceiros do Evento
- Organização e Curadoria
- Call to Action Final

### 2. Para Distribuidoras (distribuidoras.html)
Página focada em distribuidoras parceiras:
- O Papel da Distribuidora
- Por Que Vale a Pena
- Como Funciona a Parceria

### 3. Para Indústrias (industrias.html)
Página focada em indústrias parceiras:
- O Papel da Indústria
- Exclusividade e Status
- Por Que Participar

### 4. Parceiros Corporativos (parceiros-corporativos.html)
Página para empresas de tecnologia e serviços:
- Para Quem
- Por Que Participar
- Formato de Participação

### 5. Contato (contato.html)
Formulário de contato e inscrição com:
- Formulário completo
- Detecção de tipo de interesse via URL
- Informações de contato

## 🎨 Design

- **Cores principais:**
  - Azul: #0066CC (Primary)
  - Verde: #00A859 (Secondary)
  - Laranja: #FF6B35 (Accent)

- **Tipografia:**
  - Fonte: Inter (Google Fonts)
  - Pesos: 300, 400, 500, 600, 700, 800

- **Características:**
  - Design moderno e profissional
  - Totalmente responsivo
  - Header fixo com blur effect
  - Animações suaves
  - Cards com hover effects

## 🚀 Como Usar

1. Abra `index.html` no navegador para ver a página inicial
2. Navegue pelas páginas através do menu de navegação
3. Use o formulário de contato para capturar interessados

## 📝 Notas

- A seção de Programação está marcada como "EM DESENVOLVIMENTO" na home
- Os logos dos parceiros são placeholders e devem ser substituídos quando disponíveis
- O formulário de contato pode ser integrado com um backend/Supabase conforme necessário
