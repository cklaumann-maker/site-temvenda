# Página "Sobre o Projeto NEOSUL"

## Descrição

Página institucional que documenta o papel do Gerente de Vendas na NEOSUL Distribuidora Farmacêutica, detalhando responsabilidades, escopo de atuação e metodologia de trabalho.

## Arquivo

`/projetos/neosul/sobre-projeto.html`

## Acesso

1. **Através do sistema**: 
   - Fazer login no NEOSUL
   - Clicar em "Sobre o Projeto" no menu lateral
   - Abre em nova aba

2. **Acesso direto**:
   - `http://localhost:3000/projetos/neosul/sobre-projeto.html`

## Estrutura da Página

### Header
- Título: "Sistema NEOSUL"
- Subtítulo: "Gerência de Vendas Externas e Canais"
- Empresa: "NEOSUL Distribuidora Farmacêutica"

### Layout Principal

**Sidebar Direita (Fixa)**
- Card com escopo de atuação destacado
- Lista dos canais de responsabilidade:
  - Vendas externas (RCAs e coordenadores)
  - Televendas
  - E-commerce
  - Suporte operacional

**Conteúdo Principal (Esquerda)**

1. **Introdução**
   - Definição do papel
   - Diferenciação: líder de execução vs vendedor sênior

2. **6 Pilares de Atuação**:
   - Desenvolvimento e acompanhamento da equipe
   - Planejamento e governança da execução
   - Visitas a clientes e atuação em campo
   - Treinamento e capacitação da equipe interna
   - Projeto de treinamento para o varejo
   - Acompanhamento, aprendizado e evolução

3. **Papel Estratégico**
   - Posicionamento na estrutura NEOSUL
   - Especialização funcional horizontal

4. **Síntese Final**
   - Resumo das responsabilidades
   - Afirmação do papel de liderança

## Design e Identidade Visual

### Cores
- **Azul NEOSUL**: `#1e4d8b` (principal)
- **Azul Escuro**: `#163761`
- **Azul Claro**: `#2563a8`
- Gradientes azuis institucionais

### Tipografia
- Fonte: Inter (Google Fonts)
- Hierarquia clara de títulos e textos
- Espaçamento generoso para leitura

### Componentes

1. **Números de Seção**
   - Badges quadrados azuis com números
   - Visual profissional e organizado

2. **Subsections**
   - Fundo cinza claro
   - Borda esquerda azul
   - Listas com checkmarks

3. **Highlight Boxes**
   - Citações em destaque
   - Borda azul, texto centralizado
   - Itálico para ênfase

4. **Key Points**
   - Cards em grid responsivo
   - Hover com elevação sutil
   - Conteúdo conciso

5. **Final Statement**
   - Fundo gradiente azul
   - Grid de responsabilidades
   - Síntese em destaque

## Responsividade

- **Desktop**: Layout 2 colunas (conteúdo + sidebar)
- **Tablet**: 1 coluna (sidebar no topo)
- **Mobile**: Otimizado para leitura vertical

## Objetivo

Servir como documento de referência institucional para:
- Onboarding de novos gerentes
- Alinhamento de expectativas
- Comunicação clara de responsabilidades
- Base para avaliação de desempenho

## Integração com o Sistema

A página é independente do sistema NEOSUL, mas acessível através dele:
- Link no menu lateral
- Abre em nova aba
- Não requer autenticação (pode ser acessada diretamente)

## Uso Recomendado

- Consulta durante planejamentos
- Referência para reuniões 1:1
- Material de treinamento
- Documentação para diretoria
